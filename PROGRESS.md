## 2026-10-12: owner's decisions on tiers and the likely-clean tag (built, 115 tests pass)
- **Fourth outcome `LikelyClean`** (tag name to be set in settings, default `likely-clean`): clean evidence of at least 0.5 (lyrics with enough words and no scoring hits, or a "(Clean)" marker) and no explicit evidence. A playlist chooses its strictness: strict = only `clean`, balanced = `clean` + `likely-clean`, relaxed = everything except `explicit`. Below 0.5 (for example only a "(Radio Edit)" hint, now 0.4) the track is reviewed (reason WeakClean). Setting `LikelyClean` (0.5) moves the bar.
- **Word tiers (owner's list).** Severe (3): fuck and forms, cunt, the n-word and f-slur, cocksucker, shit and every compound of it (stem), bitch, dick, cock, pussy, whore, slut, tits, titty, blowjob, porn and their derivatives. Moderate (2): ass, asshole, piss (pissing, pisses), bastard, prick, twat, wanker, douche, jackass, dumbass, smartass, badass, goddamn and variants. **Mild (0, recorded but never scored): damn, hell, crap, arse, pissed.** The words are in `src/HallPass/Resources/default-wordlist.json` (the settings page will let the owner edit tiers and the allowlist).
- Dry run on the test library after the change (49 real tracks, the 12 "Test Artist" files left out): **7 Explicit, 36 LikelyClean, 6 Review** (3 instrumentals with no usable text, 3 suspects with one moderate word, "piss"). Four LikelyClean tracks carry mild words that are listed in the evidence but not scored (damn x4, hell, damn, pissed x3).

## 2026-10-12: milestone 2a done: dry-run scan, evidence store, review queue and web page (no tag writing yet)
- **Core:** `EvidenceStore` (thread-safe in-memory store, one JSON file `HallPass.Evidence.json` in `plugins/configurations`, written to a temp file first), `TrackRecord`, filtered and paged queries, stats, manual overrides that a scan never replaces, `RedecideAll` when thresholds change (no rescan), rescan rules (`NeedsRescan`: new, forced, file key changed, or evidence settings changed), fingerprints. 135 unit tests pass.
- **Plugin:** `TrackAnalyzer` (reads lyric streams through Emby, applies the scanner and the title and folder markers, skips genres), `ScanJob` (one at a time, background, progress, cancel, saves as it goes, forgets tracks no longer in the library), `HallPassApiService`: `GET /HallPass/Status`, `POST /HallPass/Scan`, `POST /HallPass/Scan/Cancel`, `GET /HallPass/Review`, `GET /HallPass/Items/{id}`, `POST /HallPass/Items/Decide` (all admin only); settings with validation (preset, likely-clean confidence, minimum words, per-word cap, skipped genres, the four tag names, `DryRun`); saving settings re-decides everything at once.
- **Web page** (dashboard, review, settings), looked at in the browser pane against the test server: tiles with counts, dry-run banner, scan card with progress and cancel; review list with filters (decision, why, sort, search, manual only), a table with decision pill, confidence, reason and evidence lines, select all, mark explicit, mark clean, clear manual decision, paging; settings form that loads and saves. Hall Pass and Hall Monitor both show in the dashboard's Advanced menu.
- **Checked live** (test library, 61 tracks): a first scan looks at all 61, a second finds 0 changed, a forced scan does all 61 again (3 seconds); a manual decision survives a forced rescan and a restart and clearing it returns to the evidence; bad input (unknown decision, empty list, duplicate tag names) is refused with 400; changing the preset re-decides at once (Relaxed made all 7 explicit tracks review, since lyrics alone give 0.75 and Relaxed needs 0.85).
- **Found and fixed on the way:** Emby writes a read-only dictionary as a list of pairs, so the status counts came out as `[object Object]`; plain dictionaries are used now. A bulk action from the page was exercised once (mark clean, then clear).
- **Not verified:** the page at phone width, the Review list with hundreds of rows, "Scan now" while Emby is also scanning the library, the scan on a large library, and cancel in the middle of a scan from the page (the button shows while a scan runs; cancel was tested only through the API code path, not clicked).
- **Still temporary:** `/HallPass/Probe/Item` and `/HallPass/Probe/Tag` (for the tag-writing work); remove before a release.
