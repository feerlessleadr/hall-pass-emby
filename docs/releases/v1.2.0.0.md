## Hall Pass 1.2.0.0

Better evidence, and much faster ways to work through a big review queue.

### Better evidence (fixes)
- **Words in a track's title now count.** A track called "Fuck You Tom" used to say "no evidence either way". A severe word in the title is now strong explicit evidence (0.85, enough on its own); a moderate word is only a hint (0.55). Mild words and clean titles say nothing. It uses the same word list, stems, allowed words and your own edits as the lyrics scan.
- **Lyric files next to the track are read.** When Emby lists no readable lyrics for a track, Hall Pass looks for a `.lrc` or `.txt` file with the track's name in its folder (any letter case, up to 512 KB), removes `.lrc` timing marks, and scans it in memory. The text is never kept.
- **A track with no lyrics now says so.** Tap a track in the review list: its evidence reads "no lyrics found: Emby lists no lyric stream for this track and there is no .lrc or .txt file with its name in its folder" (or that the lyric text could not be read), so you can tell a missing file from a real "nothing found".
- Because the evidence changed, the next "Scan now" looks at every track again.

### Faster review
- **Artists view** next to Albums: one decision for everything by an artist (it asks first, and covers every page).
- **Most played first**: sort tracks, albums and artists by how often they have been played (all Emby users added up), so what your family actually listens to is decided first. Plays are shown on each row.
- "Select all N matching" and the per-view bulk marking carry over; the phone app gets "All N explicit / clean" for the current view and a swipe mode (Embidextrous 0.8).

### Also in this version (since 1.1.2.0)
- A **"How to use Hall Pass"** card on the Dashboard with the five steps and a "You are here" line, clearer dry-run wording, and a note on the Review tab: scanning and marking are safe with dry run on, turning dry run off needs no rescan, and tracks left in review get the explicit-review tag when you Apply.

### Known limits
- Title words are matched against the word list only; a title with a clean word gives no clean evidence.
- Plays are summed from Emby's per-user counts when you ask (and kept for a minute); on a very large library "most played first" over all tracks can take a few seconds.
- Tested on Emby Server 4.10.1.0 with a small test library only; the title and lyric-file logic is covered by unit tests, and the lyric-file path was also run against real files in that test library.
