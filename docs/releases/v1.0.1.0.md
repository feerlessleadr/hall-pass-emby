## Hall Pass 1.0.1.0

Faster bulk decisions in the Review tab.

### What's new
- **Select all N matching**: tick "Select all on this page" and a link offers every track that matches the current filters, across all pages. Marking asks for confirmation and names the count.
- **Albums view**: choose *Show: Albums* to see the review list grouped by artist and album, with the decision counts of each. One click marks a whole album explicit or clean, or opens it to look at its tracks.
- Nothing is written to your files by either; manual decisions are saved like before and tags change only when you press Apply (undo still works).

### Limits
- One bulk action covers at most 20,000 tracks; if there are more, the message says so and you run it again.
- Tested on Emby Server 4.10.1.0 with a small test library only.
