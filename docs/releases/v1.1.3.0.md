## Hall Pass 1.1.3.0

Clearer instructions.

### What's new
- **"How to use Hall Pass"** on the Dashboard: the five steps in order (scan, review, preview, turn dry run off, apply), with the step you are on highlighted and a "You are here" line that follows what has actually happened (nothing scanned yet, tracks waiting for review, dry run still on, and so on).
- It now says plainly that scanning and reviewing are safe with dry run on, that you do not need to scan again after turning dry run off, and that you do not have to finish the review before applying: tracks left in review get the "explicit-review" tag, and a later Apply only writes what changed.
- The dry-run banner, the preview note and the Review tab say the same thing, and where the Dry run switch is (Settings > Tags & writing).

### Known limits
- Tested on Emby Server 4.10.1.0 with a small test library only.
