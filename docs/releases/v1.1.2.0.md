## Hall Pass 1.1.2.0

A tidier page: the top buttons are real tabs and Settings is split into sections.

### Fixed and changed
- The top buttons (Dashboard, Review, History, Try it, Settings) are now proper tabs with a visible active one, and a divider under them.
- The five word-list boxes and the "Try some text" box had no labels, so you could not tell which box was which. Each now has its name above it.
- Settings is no longer one long scroll: it has five sections you switch between (Scoring, Word list, Lookups, Tags & writing, Keeping up to date), each made of separate, clearly bordered groups. One Save still covers everything, and if the browser refuses a value in a section you are not looking at (like a batch size of 0), that section opens so you can see the message.

### Known limits
- Tested on Emby Server 4.10.1.0 with a small test library only; looked at in a desktop browser, not at phone width.
