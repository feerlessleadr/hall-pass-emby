## Hall Pass 1.0.2.0

A fix for saving the settings.

### Fixed
- Saving the settings failed with "Please enter a valid value. The two nearest valid values are 191 and 201" next to **Tracks saved at a time**. The field only accepted values 1, 11, 21 ... so the default of 200 was refused. It now takes any whole number from 1 to 2000.

### Known limits
- Tested on Emby Server 4.10.1.0 with a small test library only.
