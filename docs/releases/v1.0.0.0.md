## Hall Pass 1.0.0.0

The first release. Hall Pass works out which of your music tracks are explicit and tags them, so a smart playlist can leave them out.

### What it does
- Reads the lyrics Emby already has (embedded or `.lrc`), counts profanity in three tiers (mild words like "damn" never score) and decides **Explicit**, **Clean**, **Likely clean** or **Needs review** for every track. Lyrics are never stored.
- Optionally (off by default) asks **Deezer** and **iTunes** whether a track is explicit, sending only the artist, title, ISRC or album barcode. An online "not explicit" is weak evidence, so on its own it only makes a track *likely clean*; two independent signs make it *clean*.
- Reads each file's own tags with Emby's `ffprobe` (an explicit/clean flag when present, ISRC, album barcode).
- A **review queue** with filters, evidence for every track and bulk decisions; a manual decision always wins.
- **Preview** what would change, **apply** with a journal, **undo** from History (tracks edited since are left alone unless you force it). Dry run is on until you switch it off.
- A nightly **scheduled task** and an automatic scan of **new tracks**; both only record decisions unless you also tick "write the tags after a scan".
- Exactly one of four tags per decided track (`explicit`, `clean`, `likely-clean`, `explicit-review`, all renameable); other tags are left alone and the track's Tags field is locked so a metadata refresh cannot undo the result.

### Install
Add `https://github.com/feerlessleadr/hall-pass-emby` in the GitHub Repo Plugin Install plugin, or put `HallPass.dll` in Emby's `plugins` folder, then restart Emby. Check the download with `gh attestation verify HallPass.dll --repo feerlessleadr/hall-pass-emby`. See the README for the first run.

### Known limits
- Tested on **Emby Server 4.10.1.0** with a small test library only. Not tested on a large library, with NFO savers switched on, or when Emby stops in the middle of a write.
- Lyrics decide most tracks: tracks without lyrics (many FLAC files) end up in review unless a catalog knows them.
- Catalogs are not always right and lyrics can be missing or wrong, so disagreements go to review.
- iTunes allows about 20 questions a minute: a first scan with iTunes on is slow for a big library.
- English-language profanity only.
